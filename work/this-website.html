Project Description

The page you are reading. Plain HTML, CSS and JavaScript, written by hand, no framework, no build step, no tracking.

The layout, type and motion follow kommakomma.is closely, because copying something excellent line by line is a good way to learn why it works. GSAP handles the motion, Lenis the scroll, and the page transitions are a small hand-written router. Built with Claude Code as a pair, and every line is one I can walk you through.
